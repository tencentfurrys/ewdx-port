Generated by `analysis/v22_pov_compare.py` (full-run sweeps + ALIGN_sheet)
and `analysis/v22_pov_align.py` (swallow-aligned PHASES/ALIGNED sheets),

`report.html` (self-contained base64 preview page, ~2.9 MB) is intentionally
NOT committed. Regenerate it from the JPGs in this folder with:

```bash
cd analysis/v22_pov && python - <<'EOF'
import base64, os
imgs = ["PHASES_sheet.jpg", "ALIGNED_ref.jpg", "ALIGNED_mumu1.jpg",
        "ALIGNED_mumu2.jpg", "ref_sheet.jpg", "mumu1_sheet.jpg",
        "mumu2_sheet.jpg", "ALIGN_sheet.jpg"]
html = ["<!doctype html><meta charset=utf-8><title>POV</title>",
        "<body style='background:#111'>"]
for n in imgs:
    b = base64.b64encode(open(n, "rb").read()).decode()
    html.append("<h2>%s</h2><img style='max-width:100%%' src='data:image/jpeg;base64,%s'>" % (n, b))
open("report.html", "w").write("\n".join(html))
EOF
```
